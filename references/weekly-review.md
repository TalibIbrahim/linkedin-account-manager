# Weekly Review

Ask the user to paste (or screenshot) last week's numbers: impressions, profile views, followers gained, post-level reactions/comments/reposts, inbound DMs/leads. Don't guess numbers.

Analyze:
- Which posts beat the user's own median, and what they share (pillar, hook type, format, topic, time).
- Funnel check: impressions → profile views → connection requests/DMs → calls. Find the weakest step and fix that (e.g. many views but no DMs = profile/CTA problem, not content problem).
- Sample sizes are small; flag when a conclusion is weak and avoid overfitting to one post.

Output: 3 things that worked, 3 things to change, next week's updated calendar slots, and one experiment with its success metric.
